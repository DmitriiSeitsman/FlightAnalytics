# Flight Analytics

Самостоятельное веб-приложение для анализа Excel-отчётов `RegularInfoReport`.
Оно не зависит от CrewPlanner, авторизации или базы данных. Загруженный файл
обрабатывается локально в браузере и никуда не отправляется.

## Возможности

- устранение сдвоенных рейсов;
- средние значения по типам ВС;
- статистика по аэродромам взлёта и посадки;
- фильтры по типу ВС и аэропорту;
- показатели по КВС и вторым пилотам: минимум, среднее, максимум и сравнение со средним на типе;
- раздел «Статистика»: сравнение до пяти пилотов, график среднего и диапазона, нормализованная гистограмма распределения и выбор показателей для отчёта;
- готовые отчёты Excel и PDF со всеми выбранными фильтрами, участниками и показателями; PDF скачивается напрямую без окна печати;
- проверка обязательных столбцов исходного файла.

## Запуск

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

После запуска приложение доступно по адресу:

```text
http://localhost:3100
```

Для проверки готовой сборки:

```bash
npm run build
npm test
```

## Методика

Физический рейс определяется по дате, времени взлёта и посадки, номеру рейса и
борту. Если повторные строки содержат разные измерения, значения усредняются
внутри одного рейса. Эшелон рейса рассчитывается как среднее заполненных полей
`BD–BK`.

В исходной форме нет признака пилотирующего пилота (PF), поэтому персональная
статистика относится к рейсам, где пилот входил в состав экипажа.
Среднее для сравнения пилота рассчитывается отдельно по его типу ВС: показатели
на A-319/320 не смешиваются с B-737, B-777 или RRJ-95.
